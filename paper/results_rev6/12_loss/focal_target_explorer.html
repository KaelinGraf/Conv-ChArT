Focal target explorer

CornerNet penalty-reduced focal, as used by dcc/losses.py. σ sets which pixels get a high target value; β sets how much a given target value is worth as forgiveness. Penalty weight on a negative pixel is (1 − y)β where y = exp(−d²/2σ²).
